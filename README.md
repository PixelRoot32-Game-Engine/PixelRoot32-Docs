# PixelRoot32 Documentation

This repository contains the **official documentation site** for [PixelRoot32](https://github.com/PixelRoot32-Game-Engine/PixelRoot32-Game-Engine): guides, architecture notes, API reference, and examples.

**Live site:** [docs.pixelroot32.org](https://docs.pixelroot32.org)

## Sync from the engine

`tools/` and `examples/*.md` are generated from the game engine repo. After changing engine docs or example READMEs, run:

```bash
npm run sync-docs
```

(requires `PIXELROOT32_ENGINE_ROOT` or `--engine`; see [CONTRIBUTING.md](./CONTRIBUTING.md).)
