# Tilemap samples

Two real folders in the engine repo cover most tilemap learning paths:

| Folder | Focus |
|--------|--------|
| [`metroidvania`](https://github.com/PixelRoot32-Game-Engine/PixelRoot32-Game-Engine/tree/main/examples/metroidvania) | 4bpp tilemaps, **`StaticTilemapLayerCache`**, platformer player |
| [`animated_tilemap`](https://github.com/PixelRoot32-Game-Engine/PixelRoot32-Game-Engine/tree/main/examples/animated_tilemap) | Tile **animation**, palettes, framebuffer cache (deepest README) |

Dedicated site stubs: [metroidvania](./metroidvania), [animated_tilemap](./animated-tilemap).

For **camera / parallax** as a separate concern, use [`camera`](./camera), not `metroidvania` alone.

Guides: [Tilemaps](/guide/tilemaps), [ARCH tile animation](/architecture/ARCH_TILE_ANIMATION). API: [TileMap](/api/graphics/tilemap).

See the [samples index](./demos).
